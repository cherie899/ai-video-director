# 声音、剪辑、节奏与转场

阅读索引：声音层次 → 配乐与静默 → 剪辑动机 → 时间节奏 → 转场执行。

## 声音从行动和空间开始

先判断观众此刻需要听到什么，再分配声音层次。对白、环境、动作声、主观声和配乐可以共存，但要有主次。声音可以先于画面建立危险、引导视线、延续情绪或揭示画外行动。

| 层次 | 作用 | 分镜内需要写清 |
|---|---|---|
| 对白／画外对白 | 角色行动、关系与信息 | 原句、说话者、画内／画外、对象和必要停顿 |
| 旁白／内心声 | 特定叙述视点 | 原剧本或用户授权依据；不拿新增解释补救看不懂的镜头 |
| 环境底 Ambience | 场所、尺度、时间与连续感 | 主要声源、远近、室内外、持续范围与跨场变化 |
| 动作拟音 Foley | 触觉、重量、接触和真实感 | 脚步、衣料、门、抓握、物件何时实际发声 |
| 画外事件声 | 空间与悬念 | 方位、距离、是否被门墙遮挡、角色是否听见 |
| 主观／设计音 | 感官体验或信息强调 | 触发、声音如何变化、何时恢复客观听觉 |
| 配乐 | 情绪、节奏、主题或反差 | 画内源音乐还是画外配乐，进入、发展、退出位置 |

声源与镜头距离有关，但切近不必让所有声源都突然变大。根据听觉视点设计远近、混响、遮挡和清晰度；近距对白与远处画外喊声不采用相同空间感。

冲击声来自真正接触时刻，脚步对应落脚，门声对应开合。未接触先响、物体没移动却有拟音、道具瞬移时声音还连续，都会破坏因果。

## 配乐、主题动机与静默

先决定是否需要音乐；配乐不能掩盖台词与关键行动。音乐不必每镜重启，可在段落设定中定义连续床，再在关键镜头注明变化。

| 音乐策略 | 可服务的戏剧问题 | 执行选择 |
|---|---|---|
| 稀疏旋律／少量和声 | 亲密、思考、关系变化 | 音色、密度、进入时机，留出呼吸和对白 |
| 低频／脉冲／不稳定音色 | 压力、未知、时间逼近 | 与何种危险关联，积累幅度及释放点 |
| 管弦／合唱／铜管 | 仪式、集体、尺度或命运感 | 从哪个事件获得体量，不给普通动作强行史诗化 |
| 木管／弹拨／轻节奏 | 喜剧、日常、轻巧行动 | 喜剧主要来自行为和切点，音乐避免解释每个笑点 |
| 爵士／电子／民族器乐等 | 时空、人物或世界质感 | 是否属于场景，节奏与文化依据，不靠乐器名一键定类型 |
| 主题动机 Leitmotif | 人物、物件、概念的反复与变化 | 首次关联、再次出现的变奏及当前叙事意义 |
| 反差配乐 | 黑色幽默、疏离或主观立场 | 反差对象和观看立场，避免无意抵消应有情绪 |
| 无配乐／抽离音乐 | 真实接触、等待、冲击后的空白 | 环境、呼吸、耳鸣或绝对静音具体保留哪一层 |

需要节拍对齐时写触发事件、拍点与切点关系；没有实际音轨时只能提出节奏建议，不能编造已测BPM或已完成卡点。

“静默”要指明：仅撤掉配乐、压低环境，还是所有声音突然中断。绝对静音需要叙事理由；不把无对白误写成无声。

常用设计音包括riser、impact、低频hit、whoosh／swish、glitch和电流声；它们是可选声学功能，不是每次运镜或剪切的必配装饰。物理画面需要真实动作拟音时，先解决真实声，再决定是否加设计声。

## 剪辑动机

切镜主要由情绪、故事信息、角色视线、行动阶段和关系变化驱动。构图漂亮或到了固定秒数不自动构成切点。

一个切点应能回答：上一镜完成了什么？下一镜新给什么？注意中心怎样接上？空间和时间是否连续？必要时在动作尚未完成时切到结果或反应，但不能让观众失去关键因果。

- **反应镜头**：当听到的话或看到的事改变角色时，给反应；不每句对白机械切说话者。
- **插入镜头**：物件或身体细节必须承担信息、动作或主观感受；回到主体时状态可接。
- **空镜／余波**：表达等待、缺席、时间、事件后果或空间，不仅填满时长。
- **省略**：省去不必要过程但留下开始与结果的因果；有意省略与漏拍关键动作不同。
- **跳切**：可压缩时间或制造断裂，需在风格与节奏中明确；不要将连续性错误称为有意跳切。

## 时间预算与节奏

先算对白、动作、反应、停顿和必要读图时间，再确定镜头长度。平均镜长ASL可用于观察段落密度，但不是质量指标；长短交替也不是固定公式。

节奏可来自切换频率，也可来自镜内走位、焦点、声音、视线、遮挡与尺度变化。长镜头需要内部节拍；快切需要动作和地理依然可读。情绪落点、决定性接触、笑点后的反应与离场余波通常需要读懂的时间。

叙事节拍、成片SHOT、场景和模型生成片段是不同单位。不默认15秒一段，不按固定模型上限决定电影结构。

| 蒙太奇方式 | 用途 | 要交代的时间关系 |
|---|---|---|
| 叙事压缩 | 训练、旅程、重复劳动、长期变化 | 起止状态、代表动作、哪些时间被省略 |
| 平行蒙太奇 | 对照人物或主题 | 不一定同时，靠关联而非假因果连接 |
| 交叉剪辑 | 同时进行的行动、追赶与营救 | 各线空间、时距、进展和最终交汇是否成立 |
| 概念／隐喻蒙太奇 | 借关联物建立主题或心理 | 关联如何被观众读懂，不能取代必要事实 |
| 节律蒙太奇 | 以形状、动作或声音组织节拍 | 变化与停顿，避免只有机械等长切换 |

## 转场：写两端，不只写名字

每个特殊转场写清：**前镜离开的对象／状态 → 触发时刻 → 连接维度 → 后镜进入的对象／状态 → 成片时长与声音关系**。同时注明主要依靠拍摄设计还是后期处理；两镜切换仍是两个SHOT。

### 直接剪辑与匹配

| 手法 | 用途 | 两端执行条件 |
|---|---|---|
| 硬切 | 直接推进、反应、空间变化 | 完成何信息，下一镜注意中心与方向 |
| 反差硬切 Smash cut | 安静与喧闹、悲伤与荒诞等碰撞 | 具体反差及情绪立场，不能随机惊吓 |
| 动作匹配／动势接力 | 连续行动或跨时空关联 | 动作阶段、方向、速度与力量方向；不能把跨时空误当同一动作 |
| 图形／形状匹配 | 视觉记忆、概念关联 | 对应轮廓、画内位置、尺度或运动，后镜对象可辨 |
| 色彩／明度匹配 | 情绪与空间平滑或反差 | 前后主色区域、亮度与主体注意中心 |
| 视线／方向匹配 | 顺势揭示对象与下一空间 | 谁看向哪里，后镜回应什么，屏幕方向成立 |
| 对白钩子／概念切 | 问答、关键词、主题关联 | 前句落点与下场回应；改动原台词须获批准 |

### 声音驱动

| 手法 | 正确定义 | 执行说明 |
|---|---|---|
| J-cut | 下一镜／场的声音在画面切换前先进入 | 从前镜哪一刻起，声音属于后场何处，切画面后如何确认 |
| L-cut | 上一镜／场的声音延续到下一画面 | 延续到何时、为何留住声音，下一画面如何承接 |
| 声音桥 | 一个声源或声学关系连接两场 | 声源是否同一、是否跨时空，变化处在哪里 |
| 相似音匹配 | 两个不同声源有相近声学特征 | 比如猫叫接汽笛：音高／长度／节奏哪项相接，后场声源需要被确认 |
| 骤停／重音切 | 中断声音或借impact进入新镜 | 哪些音轨停止、停多久、何时恢复；重音是否覆盖对白 |

声音先后不自动改变画面时长总和；J/L-cut的音轨重叠不能当作两画面叠化扣时。

### 摄影机与物理遮挡

| 手法 | 执行条件 | 避免的缺口 |
|---|---|---|
| 前景遮挡 Pass-by wipe | 实体前景沿明确方向盖满画面，再从匹配遮挡揭出后场 | 遮挡不够满、方向不接、厚度与速度突变 |
| 甩镜接力 | 前镜甩出与后镜甩入方向、模糊和速度相接 | 不能只写“快速摇镜转场”而没有落点 |
| 推入／拉出穿透 | 前镜某物充满视野，后镜由对应形态或暗部展开 | 指明遮切／匹配／后期合成，不能把不可穿透实体当透明通道 |
| 升降／轴向接力 | 前镜升向天空／顶面，后镜从相应区域下降显露 | 运动方向、亮度、空间重建，不必冒充同一真实连续镜头 |
| 光线遮切 | 车灯扫过、阴影或光区覆盖画面 | 光源真实存在；覆盖后进入何处，是否需后期 |

### 光学、时间与形式

| 手法 | 叙事用途 | 执行条件 |
|---|---|---|
| 叠化／溶解 Dissolve | 时间流逝、记忆、关系叠置 | 前后图像重叠时主体位置可读，时长及重叠量明确 |
| 淡入淡出／黑场 | 章节、间隔、结束或重新开始 | 黑场是否计时，声音是否持续，不用每场都淡出 |
| 闪白／曝光闪烁 | 主观转折、强光或记忆冲击 | 触发与恢复，真实光源还是后期处理 |
| 划像／圈入圈出 | 复古、漫画感或形式节奏 | 开合方向、遮罩形状与持续时间 |
| 拼贴／分屏 | 同时呈现并行事件或对照信息 | 写清各窗口的位置、起止、时间关系与主声音。分路生成时分别描述画面，按同一时间轴交给后期合成 |
| 旋转／缩放／动态模糊 | 主观、速度或形式连接 | 是真实相机运动还是画面变换；两端几何与速度匹配 |
| 定格 | 强调、叙事停顿或章节 | 停哪一帧、多久、声音如何继续，之后怎样离开 |
| 同机位延时 | 一个空间的时间跨度 | 固定锚点、人物与光影变化、时间压缩证据 |
| 无缝形变 Morph | 梦境、身份、材质或时空演化 | 锁定哪些轮廓／机位，哪些属性变，何时完成；注明为特效需求 |
| 胶片灼烧／漏光／粒子／水墨 | 明确风格化连接 | 视觉机制与叙事理由、合成端点；不当默认电影感 |
| 倒放 | 时间或形式反转 | 哪段被反转、信息是否仍成立、声音是否单独处理 |

连续镜头中真实经过门框只是镜内遮挡；只有借此切换片段才是遮挡转场。视觉特效变形不等于AI工具一定能一次完成，分镜只明确所需结果与衔接条件。

## 最后检查声画是否彼此负责

关键声音有来源、时间和听觉视点；音乐有进入／变化／退出；切点有信息或情绪理由；特殊转场两端都已设计；相邻动作与空间可接；时间预算覆盖停留与过渡。精确响度、混音数值或音乐节拍只有在实际素材或交付规格支持时才填写。
