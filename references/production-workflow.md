# 制作流程

剧情线与萌宠线共用本流程。用户当前明确要求优先；阶段已确认则沿用，修订仅重新确认受影响的部分。

仅加载当前阶段需要的规范，已读且仍有效的内容直接复用。

## 开始项目

1. 完整制作时阅读完整剧本，查看已有素材，核对剧本版本、预期时长、画幅和风格；缺少剧本先索取，不自行编故事。单独制作资产等局部任务只核对本阶段必需的信息，不强求完整剧本。未指定画幅默认16:9。
2. 开始生成图片前读取[图片规范](image-standards.md)，确定用户指定的输出目录；已有指定直接沿用，未指定先询问。素材检查和文字分析可先进行。

局部任务只执行所需阶段及必要前置检查。只要求分镜式 H3 时，可依据剧本与现有素材直接进入阶段4；无参考素材可用文字生成模式，不为流程补做图片。只有已给定画面设计的格式转换才直接交给 H3 技能。拉片、复刻、叙事故事板和联系图按明确请求进入[按需能力](optional-workflows.md)。

## 共用约束与进度

- 原文对白、人物关系、事件顺序、因果和结局是依据；导演可以补充机位、表演、微反应、动作衔接和环境声音。会新增事件或改变事实含义的视觉联想先作为提案确认。
- 以聊天记录维护当前制作线、确认过的视觉重点、选用图片版本、当前批次及待确认项。阶段1、4直接在聊天窗口交付；阶段2、3交付图片，不自动新建剧本归档、清单、分镜、质检、交接或提示词文件。
- 按顺序完成当前阶段的全部批次，再进入下一阶段。每个指定确认点等待用户回应；部分通过时只修订未通过项，不将其作为下游输入，不提前生产下一批。
- 台词按清晰语速、表演和理解时间估时；总时长、分段、切点及镜内节点使用0.5秒整数倍。内容放不下时提出拆段或时长调整，不删词或靠超速硬塞。

## 阶段1：剧本文案 → 视觉重点

按语义段落提炼原文对应、需要让观众看懂的重点与拟呈现画面。抓住关键事件、关系、转折及解释信息；导演建议的具体颗粒度遵循所选制作线的细则，未另作规定时保持简短。区分脚本明确画面和导演建议，不逐句扩成完整分镜；在聊天中统一确认后进入资产阶段。

遇到抽象概念或解释性内容，先把原文里的因果变成可看见的过程：选一个具体载体，写清谁对它做了什么、画面上改变了什么，再定镜头。原文只说到条件、威胁或尝试时，画面也停在对应状态。试着只看画面，判断观众能否看懂谁引发了什么变化。

只要阶段1画面建议时，有剧本即可开始。导演按[拍摄方式](storyboard-direction.md#拍摄方式)给出建议。

## 阶段2：资产梳理与补齐

结合已确认的重点检查角色、场景和道具。已有图片实际可用且足够时直接复用，不因版式不同重做；只补缺失或无法支撑一致性的部分。

依次执行：

1. 制作缺少的角色资产图 → 展示并等待确认。
2. 制作缺少的场景资产图 → 展示并等待确认。
3. 制作必要的复用道具图 → 展示并等待确认。

没有缺口的类别说明复用结果后跳过制作；已有确认也不重复索要。一次性出场的道具不单独制作资产，可在场景或关键帧中呈现。同一道具会跨镜反复出现且需锁定外观时才单独建图。

生成、版本及检查均按[图片规范](image-standards.md)执行。类别确认前不制作下一类别。

## 阶段3：图像制作

默认优先制作核心关键帧。[叙事故事板](optional-workflows.md#叙事故事板)和[关键帧联系图](optional-workflows.md#关键帧联系图)仅在明确请求时交付。单做故事板可直接用现有剧本和素材，单做联系图使用已有的已确认关键帧。

### 核心关键帧

按[图片规范](image-standards.md#生图前的视觉设计)先完成视觉设计，再确定关键帧。复杂互动和调度按[分镜导演规范](storyboard-direction.md)补读。

用已确认的视觉重点和资产选择少量剧情锚点。约每30秒5张是效率参考，不是按6秒固定采样或必须凑满；同一张可支撑多个镜头或视频段。仅视角、表情和连续动作变化通常不新增图片。

每张独立呈现一个完整情境，锁定必要的主体、空间、关系、情绪或关键动作状态，并留有前后演绎空间。这些图用于全能参考，不默认绑定生成视频的首帧或尾帧，也不作为多格拼图交付。

先估算剧情覆盖与总时长，再按剧情顺序每批最多5张实际制作；不足5张按实际数量。逐张检查后在聊天标注编号、对应原文、作用及文件链接 → 用户确认 → 下一批。全部批次确认后进入阶段4。

## 阶段4：直接交付分镜式 H3

读取[分镜导演规范](storyboard-direction.md)及其中的[阶段4装配](storyboard-direction.md#阶段4装配)。导演在同一次任务中完成镜头设计，并调用 [H3技能](../skills/h3-prompt-writing/SKILL.md)装配完整提示词；不先交独立导演构想或中文分镜等待二次转换。

以原文、已确认重点和当前采用资产为依据，按实际播放顺序写清每镜画面、机位、主体行动、表演、必要光色、声音和衔接。镜头数与生成段分别由叙事和时间预算决定。已有确认的路线继续沿用，不借装配重做设计。

完整制作中，若重要画面缺少必要资产或关键帧，说明具体缺口并回到相应图片确认点；用户已选择无图文字生成时不强制补图。会改变原剧情、原台词或锁定项的调整仍需确认，先推进不受影响部分。

交付格式、语言、上传映射和批次统一按 H3 技能执行。用户确认本批分镜式 H3 后继续后续批次。本流程默认聊天交付，不自动保存文件或生成视频。

## 交付核对

核对原文覆盖与对白、选用版本、参考用途、状态连续、时长和当前确认节点。图片须实际查看，文字与语法通过不等于成片验证；如生成或保存失败，说明具体缺项与受影响阶段。
