# 分镜导演规范

供剧情导演与萌宠导演共用。核心关键帧是素材锚点，镜头是连续画面，生成段是一次生成任务，三者不要求一一对应。

## 先形成导演决策

先确定观众要理解什么、角色目标、阻力与信息变化，再组织行动、反应和解释画面。每镜承担具体作用，开头、转折与结尾遵循原文，不提前揭晓后段信息。

导演设计同时考虑表演、空间、摄影、光色、声音和剪辑；把有效决定直接写入分镜式 H3。摄影设备和技术参数只在影响可见结果时选择，不把知识表格变成每镜必填清单。

## 拍摄方式

导演根据剧本和用户想要的效果设计常规分镜。用户明确描述特殊拍法时直接采用，导演也可在画面建议中推荐合适的拍法并简述作用。只有不同拍法会明显改变观看体验、且无法判断用户偏好时，才用日常话询问想要的效果。相容拍法可按段组合。H3 输入模式按实际素材用途选择。

### 镜头怎么组织

常规多镜头根据剧情变化切镜。[场面调度](story-staging.md#镜头功能与覆盖)处理同一事件的多角度覆盖，[时间预算与节奏](sound-editing.md#时间预算与节奏)处理蒙太奇、时间压缩和交叉剪辑。

| 常见拍法 | 导演要落实的约束 |
|---|---|
| 一镜到底 | 本段全程无切镜。机位移动时路线要走得通，用动作或同一物件衔接前后节拍。跨生成段按[分镜装配约定](#全片镜头与生成段)执行。 |
| 伪一镜到底 | 保持画面连续的观感。用[遮挡、甩镜或匹配转场](sound-editing.md#摄影机与物理遮挡)设计隐蔽切点，写清切前如何遮住接缝、切后从哪里继续。实际切镜分别编号。 |
| 长镜头组接 | 用多个较长镜头串起剧情。每镜有可读的起落，按叙事重点、视角或时空变化安排切点。 |

### 视角与画面形式

| 常见形式 | 导演要落实的约束 |
|---|---|
| 第一人称（POV） | 观众从指定人物或动物的眼睛看。保持对应眼高、朝向和可见范围。 |
| 固定机位 | 从同一位置和角度观察。先构好画面，让人物或动物的进出、动作和状态变化在画内读得清。 |
| 自拍或设备记录 | 让观众像在看角色手机、监控或行车记录仪拍到的画面。明确设备的位置、可见范围和它如何随持机者移动或保持固定。 |
| 纪录片式／伪纪录片 | 用观察、跟拍、采访或现场声推进信息。明确镜头是在旁观，还是被角色察觉并成为交流对象。伪纪录片以虚构剧本为表演依据。 |
| 桌面电影 | 让屏幕里的操作和反馈推进故事。写清窗口、光标或触控的顺序，留出阅读关键界面信息的时间。 |
| 拼贴／分屏叙事 | 需要同时展示并行事件或对照信息时，按[分屏设计](sound-editing.md#光学时间与形式)执行。 |

完整分镜覆盖上述视听维度；已清楚的普通选择直接执行，复杂问题或局部修订只补读相关章节及相邻镜头。表中链接是问题索引，不是全量必读清单；调用方已经加载且仍有效的装配约定等内容直接复用。

人物或动物表演遵循所选制作线及已确认形态，不把成人裁切、手掌动作、站立和口型默认套给自然动物。混合出镜仍保持一个明确的叙事注意中心。

## 工作流与验证边界

确认点、聊天或文件交付由调用方工作流决定，本规范不新增中间确认稿、交接文件或图片任务。视频拉片另按[视频证据规范](video-evidence.md)记录实际观察范围。

静态图只能验证当下画面；运动、口型、时序成像和声画接缝须待实际视频检查。导演权限内先修正；涉及原剧情、台词或锁定项的变更交用户决定。

## 阶段4装配

本节在交付分镜式 H3 时读取，格式与交付统一遵循 [H3 技能](../skills/h3-prompt-writing/SKILL.md)。

### 先设计，再直接写入正文

每镜先确定目的、时长、主体与空间起态、主要行动、摄影、必要光色、对白和声音、终态与下一镜的连接。内部检查完成后直接装配，不要求用户先批准一份中文构想再转换。用户已有确认的镜头继续沿用；触及故事或锁定项的变化先处理权限。

| 导演决定 | 模型正文应包含的内容 |
|---|---|
| 观看对象与关系 | 当前景别、机位、构图、视线和必要空间锚点 |
| 表演与动作 | 触发、可见回应、准备、接触、受力或所有权变化、结果 |
| 摄影与焦点 | 主体与摄影机分别的路径、速度、遮挡、关注对象和落点 |
| 光色与材质 | 本段有效视觉基准及在相应镜头发生的变化 |
| 原台词与声音 | 每个节拍的出镜角色、实际说话者、发声位置、原文、动作音时机与声画承接 |
| 连续性 | 相邻镜头与生成段的姿态、持物、动作相位、视线和声场状态 |

这些内容进入当前模式的时序主字段，而不是只留在块外说明。每段描述足以执行，不压成故事梗概；也不为凑字段重复人物小传、堆器材名或虚构精确参数。

### 有效设定与局部变化

设计时可按全片、场景、单镜组织共享设定。每个独立 H3 代码块展开该段实际生效的身份、空间、视觉、声音和起态，不依赖“同上”。单镜改变焦距、焦点、光色等后，在下一镜明确继续采用新值还是恢复原值。

同一物理空间保持真实光源与固定方位；画面左右会随机位变化。关键接触和两主体关系必须可读，不能用虚化、遮挡或过早切镜隐藏因果。

### 全片镜头与生成段

- 全片 SHOT 连续编号，表示实际连续画面；切镜另起镜头。核心关键帧、SHOT 与生成段不是一一对应。
- 按 H3 当前时长范围组织生成段，一个生成段可含多个镜头；同一长镜也可由连续生成段承接。生成段边界不自动增加电影切镜。
- 跨段长镜、局部修订或参考复刻涉及镜头对应时，区分全片 SHOT、源镜和段内镜号。块内镜号与切点遵循 H3，段内切点按本段时间计算。
- 一镜到底跨生成段时，优先依据已确认终态或实际可用的承接素材写清本段起镜的构图、站位、动作相位、持物、视线、速度和声场。只有计划终态时，按设计写明本段起态并标明待实片核对。交接不重演，道具不复原。沿途的故事板取样仍属于同一长镜头。不同生成任务的声画接缝须看实片核验。
- 其他模式按剧本和本段镜头设计写全起镜构图、站位和持物。叙事连续时保持剧情所需的状态，机位和构图随本镜设计。
- 对白、反应、动作与转场留足理解时间。放不下时给出延长或拆段方案，不删原词、超速硬塞或悄悄新增事件。
