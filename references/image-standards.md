# 图片规范

适用于两条制作线；项目明确指定的比例、风格、构图优先于默认值。已有素材满足用途即可复用。

## 格式与视觉

| 类别 | 默认要求 |
|---|---|
| 角色资产 | 横版16:9，纯白背景；左侧脸部特写，右侧为同角色不含头部的正面、背面身体全貌。作为设计拆解呈现，无伤口。专业写实影像，真实皮肤或毛发，柔和均匀光照，避免油光和强反光 |
| 场景资产 | 横版16:9，完整环境，无角色（无人、无动物）；保留空间结构、固定物件、光源与可用行动区域 |
| 道具资产 | 1:1，单个道具一张，纯白背景，外观与状态清楚 |
| 核心关键帧 | 单幅完整剧情情境，比例跟随成片，默认16:9；沿用已确认资产与项目风格 |

默认避免霓虹光效、雨夜、潮湿反光地面、僵硬肢体及违反物理或身体运动逻辑的动作。明确要求电影感时表现自然明暗与色彩过渡、合理冷暖对比及有来源的光影，不用生硬光效替代。

## 生成与检查

- 实际生成或修改图片时读取当前 `imagegen` 技能，优先内置 `image_gen`；按实时工具能力传入引用，先查看参考图，明确各图用于身份、空间还是道具状态。
- 一张核心关键帧一次独立生成，不拿拼图裁切冒充多张。资产多视图本身属于一张角色资产。
- 逐图查看身份、数量、形态、比例、接触与支撑、道具状态、空间、光线和必要信息是否清楚；用当前制作线补充表演检查。明显错误先定点修正，每图默认最多2次，仍失败则说明，等待用户处理。
- 图像检查合格后仍需经过流程指定的用户确认；代理质检通过不等于用户已经确认。
- 使用工具实际返回的可保存文件，复制到用户指定输出目录，确认可打开和真实尺寸。工具不支持直接指定保存位置时，不虚构路径参数。比例不符时用生成/编辑工具修正，不拉伸或仅改扩展名。
- 不自动切换付费API；工具不可用时说明受影响的制作步骤。

## 路径与版本

图片直接保存到用户指定目录，不自行追加类型或运行版本子目录。原有素材保持原路径。

文件采用稳定编号和可读名称，例如 `CHAR_001_角色名_v01.png`、`SCENE_001_研究室_v01.png`、`PROP_001_道具名_v01.png`、`KF_001_v01.png`；修改版使用同一编号递增 `_v02`、`_v03`，不覆盖旧图。沿用项目已有编号与命名时无需改名。

后续默认使用**最新已确认版本**。版本号最高的待确认或被否决图片不能替换已确认图；对旧版本作局部修改时仍生成新版本。每批在聊天中注明待确认版本及通过后采用的版本；确认记录不清楚时核对用户选择，不单凭文件名或修改时间推断。
