# 光色、美术与成像参考

## 先定义可见结果

统一视觉设定回答：故事发生在哪种物理环境，观众首先注意哪里，明暗与色彩怎样表达已有关系，人物与环境如何分离，材质要保留什么。机身、镜头、胶片、LUT与风格名只提供参考，不能代替这些决定。

用户知识图是方法来源，不是全部项目的固定色板。不得默认青橙、粉彩、日落、雾气、湿地反光、过强锐化或极浅景深；具体选择来自本任务已确认的故事、素材与风格。

## 动机光源与连续布光

先固定空间里的窗、灯、天光、火焰或屏幕位置，再写它们如何照到主体。灯光“来自画左”只适用于当前机位；反打后保持真实光源方向，不把光源随摄影机搬到另一边。

一个可执行的布光描述通常包括：**光源依据、相对方向与高度、软硬、主辅关系、主体与背景亮度层次、色温关系、必要反射／遮挡**。不要求每镜重复所有信息，段落设定负责共享值。

| 术语 | 实际功能 | 需要区分 |
|---|---|---|
| 主光 Key | 塑造主体主要明暗 | 不必是最亮的画内灯，也不必正面照 |
| 辅光 Fill | 调整阴影可读性 | 补光不能无意抹平应有造型；可用反射或负补光控制 |
| 轮廓／侧逆光 Rim/Kick | 与背景分离、强调边缘与材质 | 角度、强度与光源动机；不是所有边缘都发光 |
| 实用光 Practical | 画内可见且成立的灯／火源 | 真实发光物、其照明贡献与补光是不同层次 |
| 环境光 Ambient | 提供空间基础照明 | 仍有方向、色调和遮挡，不等于均匀照亮 |
| 负补光 | 吸收环境反射，使暗面更有形 | 暗面位置与关键细节保留程度 |
| 光比／明暗关系 | 决定主体塑形与背景分离 | 没有测量时描述相对层次，不伪造现场照度 |
| 色温关系 | 区分光源与空间 | 相对冷暖与白平衡共同影响结果；夜景不必全蓝 |

## 常用布光选择

| 模型／条件 | 可服务的场景 | 执行与误用检查 |
|---|---|---|
| 窗侧柔光／阴天散射 | 生活感、克制对话、细节观察 | 宽大光源与柔和过渡；保留脸部和空间层次 |
| 黄金时刻低角度光 | 暖意、告别、体量轮廓 | 给出太阳方位与可见天空关系，不用于所有情绪 |
| 月光／夜间环境 | 夜路、等待、冷暖室内外 | 来自何处、暗部能否看清行动；避免凭空顶光 |
| 硬侧光 | 形体、纹理、遮挡和强烈冲突 | 阴影边缘、反射与人物转头后的光影变化 |
| 顶光／底光 | 空间条件、压迫或主观异常 | 先成立光源；底光不自动等于恐怖 |
| 逆光／剪影 | 隐藏身份、离别、环境比例 | 需要隐藏什么、哪些动作仍可辨；不丢关键表情 |
| 明暗对照 Chiaroscuro | 强明暗结构、心理与关系 | 明暗区域有构图与叙事作用，不把低曝光当设计 |
| 伦勃朗式 | 有方向的人像造型 | 阴影侧脸颊三角亮区可作为特征，不机械追求几何形 |
| 分割光 Split | 将面部或空间分成明暗两部分 | 两侧关系与视线可读，避免脸部关键变化消失 |
| 蝴蝶光 Butterfly | 正面人像、对称造型 | 较高正面主光形成鼻下阴影，注意眼窝与角色适配 |
| 高调／低调 | 明亮轻盈或低亮度选择性信息 | 指整体明暗分布；高调不等于过曝，低调不等于看不清 |
| 多区域布光 | 纵深场面、前中后景行动 | 每区有主次，人物移动时如何进入／离开光区 |
| 烛火／灯火 | 私密、年代、微小光源关系 | 火源位置、肤色和背景层次，摇曳幅度有节制 |
| 霓虹／彩色光 | 人工环境、身份或空间区分 | 真实发光物和反射方向，不让所有肤色失真 |
| 体积光／光束 | 路径、空间、隐藏与显露 | 需要空气中可见散射条件；未经风格确认不强加雾尘 |

## 色彩是跨镜头的叙事关系

设计时一起考虑色相、饱和度、明度、冷暖、面积、光比与场景语境。红色可能是危险、亲密、制服或日常物品，意义由故事和重复使用建立，不采用“某色必然代表某情绪”的字典。

| 系统 | 用途 | 可执行描述 |
|---|---|---|
| 低饱和／有限色板 | 克制、生活感、信息集中 | 哪些色降低，肤色／关键物是否保留，亮暗如何分层 |
| 高饱和／鲜明对比 | 形式、活力、冲突或奇观 | 强色面积与主次，避免所有元素争夺注意 |
| 同色／邻近色 | 统一、包围、平静或压迫 | 用明度、材质和局部色差保持主体可辨 |
| 互补／冷暖对照 | 空间分区、关系冲突 | 对照发生于灯光、服装还是环境，避免全片无差别青橙 |
| 暖灰、米色、棕色 | 可支持日常、年代、土地或安稳 | 暖度、材质和光向，不单靠泛黄滤镜 |
| 青灰、银灰、深蓝 | 可支持疏离、技术、秩序或夜景 | 关键暖色与肤色如何保留，不把阴影全部染成一种色 |
| 黑白 | 明暗、形状、纹理、主观回忆 | 设计灰阶分离，彩色差异可能在黑白中消失 |
| 黑金／金属色 | 仪式、权力、财富或工业质感 | 金属反射、暗部层次和色彩面积，不是仅写“高级” |
| 粉彩／梦幻色 | 可支持童话、浪漫或反差喜剧 | 饱和度、亮度、材质与表演共同成立，不固定某个导演标签 |
| 色彩转折 | 连接人物变化或信息揭示 | 从哪镜开始、由何光源／空间／道具引发，幅度多大 |

为场景或角色建立有限的色彩关系，而非每镜随机改色。人物从室外冷光走入暖室内，说明过渡时点、混光位置与镜间衔接；相同时间反打不应突然变成另一色板。

## 风格标签转成工作规则

命名参考后，至少落实到构图、空间、美术材质、表演、镜头运动、光色与剪辑中的相关项。参考贡献哪些机制要具体说明，不能仅写“电影质感”。

| 风格方向 | 应具体化的选择 |
|---|---|
| 对称、粉彩、复古形式喜剧 | 正面／剖面空间、中心或对称、道具重复、节制表演与精确切点 |
| 现实／纪实／公路 | 环境与人物距离、可见生活行为、自然动机光、观察或跟随方式；手持可选 |
| 黑色电影／暗黑／悬疑惊悚 | 选择性信息、遮挡、明暗结构、主客观视点与声音先后，而非只有压暗 |
| 温暖日常／清新青春／柔和人像 | 自然色与肤质、光线方向、人物距离和表演尺度，不自动加柔焦 |
| 赛博／科幻／未来 | 世界功能、人工光源、材质、界面与尺度，科技必须具体可见 |
| 废土／史诗 | 资源与磨损、环境比例、群体地理、行动重量和宏观视角的理由 |
| 东方古风／水墨 | 建筑、服装、材质、留白、空间层次与节奏；不能仅套“中国风”滤镜 |
| 奇幻／梦境／超现实 | 现实基准、异常规则、触发和结果；变形与时空跳转明确由谁感知 |
| 浪漫／文艺／孤独观察 | 观看距离、等待、关系留白、环境和声音，不只日落与慢动作 |
| 动作／暴力美学 | 空间、力量、后果、色彩和剪辑对照；风格化也要看懂接触与结果 |
| 90年代香港武侠／无厘头／怀旧胶片 | 当次参考中的场景材质、动作节奏、喜剧反应、镜头组织和颗粒色调；不以片厂名代替设计 |
| 都市时尚／MV | 姿态、轮廓、材质、光学与节拍，区分故事行动与展示性动作 |

这些类别可交叉，具体参考优先。用户只需要某个镜头机制时，不连带移植整套服装、剧情或审美。

## 成像技术：四层分开

1. **采集／模拟路线**：数字电影参考，或胶片摄影参考。
2. **镜头与曝光倾向**：画幅、像圈、焦距、光圈、焦点、运动拖影；依据可见目标选择。
3. **数字编码／调色**：Log、工作色域、扫描后调色、LUT的角色，不把它们当画面效果的万能保证。
4. **显示／交付**：SDR／HDR及明确的显示变换、色彩规范；用户未要求真实后期技术交付时，不添加假规格。

**数字路线写法**：以某数字电影系统为成像参考，肤色自然、亮部滚降柔和、暗部有层次；需要技术工作流时再说明Log和显示转换。Log不是HDR交付，Rec.709也不是某个电影风格LUT。

**胶片路线写法**：ARRICAM LT＋适配Super35的镜头＋KODAK VISION3 500T 5219作为视觉参考；说明颗粒、色彩、高光与材质。5219为钨丝灯平衡彩色负片；日光条件下的滤镜／白平衡／调色倾向若与任务有关须明确。不要把ARRI LogC3写成胶片摄影机原生采集参数；扫描后的数字流程可另说明。

“细颗粒随帧变化”是时序影像效果要求，文本只能提出，静帧不能验证其时序表现。“胶片感”也不等于固定泛黄、刮痕、漏光与抖动全开。

设备适配需要检查画幅、接口和像圈，不把安装得上等同覆盖全画幅。Cooke S4/i S35与S4 FF/i是不同系列；S4/i S35不笼统保证覆盖LF完整模式。没有具体规格时，选择兼容的参考或只写视觉目标，不伪造认证。
