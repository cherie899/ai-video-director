# 按需能力

仅在用户明确请求相应能力时读取，不增加默认四阶段的产物。

## 拉片与复刻

先读取[视频证据规范](video-evidence.md)，按实际可访问的声画范围逐镜记录。只分析已验证范围，不将观察事实、用户资料与导演推断混写。

复刻时先对齐保留程度：R1逐镜结构、R2核心创意与标志性镜头、R3视觉风格、R4概念再创作。未指定时推荐R2供用户选择。提出具体保留与改动项、目标镜头及源镜对应，经确认再制作。R1保留源镜头数与顺序；与已有剧本冲突时列出冲突交用户取舍。已有剧本保持剧情与对白；无剧本则先基于确认方案拟定并确认剧本，再进入共用流程。

只要求拉片或方案时到此交付，不自动出图。默认在聊天交付；只有用户要求文件时才保存对应文档。

## 关键帧联系图

使用全部已检查且经用户确认的独立关键帧进行排版，不生成新剧情图。读取本次计划中选用的版本，缺失、待确认或失败时先解决，不用占位图交付完成版。

在项目外临时目录准备清单。图片路径按清单所在目录解析，执行时替换为实际有效的相对路径或用户提供的路径；以下仅为相对路径示例，不要求移动原图：

```json
[{"id":"KF_001","path":"../project-images/KF_001_v02.png","status":"passed"}]
```

使用 Python 和 Pillow 运行[联系图脚本](../scripts/make_contact_sheet.py)，输出先放临时目录：

```text
python <本包根目录>/scripts/make_contact_sheet.py <临时清单.json> <临时联系图.png>
```

工具只检查文件与排版，调用前必须自行确认清单完整、全部通过且版本正确。查看成图的格数、顺序、标签和画面后，再以未占用的版本名交付至用户指定目录；原图不改动。清单是临时执行数据，不自动成为项目交付文档。
