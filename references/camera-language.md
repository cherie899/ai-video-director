# 摄影与镜头语言

阅读索引：景别与机位 → 构图与画幅 → 镜头与焦点 → 运镜 → 组合与校对。

## 分开描述四个维度

“中近景、A的过肩、平视、固定”分别回答距离、关系构图、角度和运动。叙事核心／辅助是功能；Master是场面覆盖组织，均不等于景别。

| 景别 | 主要信息能力 | 使用与限制 |
|---|---|---|
| 大远景／远景 ELS | 环境尺度、地理、孤立感或奇观 | 人物识别与细动作不一定读得清，关键行为不能只依赖它 |
| 全景 LS | 全身动作、路线、人物与环境关系 | 留出实际动作空间，注意脚和接触点 |
| 中全景 MLS | 身体姿态与互动、局部环境 | 不靠人体固定裁切规则处理所有体型 |
| 中景 MS | 关系、手势、说话与行动 | 手部重要时确保在画内，不因惯用腰线切掉关键动作 |
| 中近景 MCU | 表情与上身反应 | 可保留少量关系前景与视线空间 |
| 近景 CU | 面部反应、亲密观察 | 靠近不自动等于情绪更强，需有变化值得观察 |
| 特写／大特写 ECU | 眼神、手部、道具或感官细节 | 指定观看对象与信息可读程度，不只写“特写” |

不同教材对近景、特写的命名略有差异；以可见范围和实际叙事信息消除歧义。动物、非人角色与产品按其尺寸和动作描述，不机械套成人胸腰裁切。

过肩、双人、多人同框、单人、POV是关系或视点组织；同样可以具有不同景别。“群像”若指叙事结构要与画面中的“多人同框”区分。

## 机位、角度与观看关系

机位写相对主体和空间锚点的位置、视高、朝向与距离；没有可验证测量时用可执行的相对关系，不伪造厘米级现场数据。

| 角度／位置 | 常见作用 | 具体决定 |
|---|---|---|
| 平视 | 平等观察、克制或直接关系 | 与谁的眼高齐平，不能默认成人高度 |
| 仰拍 | 强化体量、环境压力或主观敬畏 | 是主体显强，还是空间压住主体；脸部透视与背景信息 |
| 俯拍 | 交代位置、暴露、脆弱或旁观 | 高度与角度，是否仍看清眼神和动作 |
| 顶视 | 几何关系、路径、群体与物件布局 | 俯视空间锚点，人物不能突然失去方向 |
| 贴地低位 | 身体尺度、速度、动物视点 | 距离、地面质感、脚／爪与障碍可见性 |
| 高位／俯瞰 | 地理、路线、系统性或超然感 | 不能只因宏大而丢失当前角色目标 |
| 倾斜机位 Dutch angle | 失衡、主观不安、特殊形式 | 倾斜的触发与恢复点，不随机每镜歪斜 |
| 背面／侧面／正面 | 隐藏表情、展示关系或直接对峙 | 哪项信息被保留或延迟；人物是否有意看镜头 |

角度不具有唯一情绪含义；先看人物行为、镜头时长、尺度与剪辑上下文，再判断效果。

## 构图工具及用途

构图必须同时安排主体、关系、前中后景和观看路径。先决定观众第一眼看哪里、第二眼发现什么，再选名称。

| 手法 | 适用问题 | 执行要点／常见误用 |
|---|---|---|
| 中心构图 | 集中注意、仪式、直接对峙 | 区分主体居中与全画面对称；背景要支持中心 |
| 对称／平衡 | 秩序、静态关系、形式喜剧 | 对称可被人物行动打破，变化本身可讲故事 |
| 三分法／偏置 | 视线或运动空间、关系留白 | 重心放置服务行动，不为格线强挪角色 |
| 负空间／留白 | 等待、缺席、威胁或孤独 | 明确空位等待什么；不是随意让人物变小 |
| 框中框 | 门槛、隔离、观看与空间深度 | 门窗归属真实，不能靠框挡掉关键动作 |
| 前景遮挡 | 观察感、隐藏、层次与揭示 | 谁／什么遮挡，遮挡如何随动作改变 |
| 引导线 | 目标、路线、纵深 | 线最终引向叙事对象，不只漂亮消失点 |
| 对角线／斜向 | 动势、失衡、距离与阻力 | 屏幕方向与实际路线一致 |
| S形／曲线 | 流动、绕行、延迟揭示 | 主体沿什么路线前进，何时显露目标 |
| 三角／L形组合 | 多人关系、包围、层次与稳定 | 角色间实际权力与视线，而非摆姿势 |
| 圆形／放射／螺旋 | 聚焦、循环、空间组织 | 环境确有结构支持，不强行叠几何线 |
| 重复／节律 | 集体、秩序、流水线、差异个体 | 用变化或破格建立信息中心 |
| 大小／明暗／色彩对比 | 规模差、主次、关系冲突 | 主体辨识与光色动机一致 |
| 层次与纵深 | 多条行动线、等待与发现 | 规定各层动作和焦点，不是所有背景都虚化 |
| 浅景深构图 | 隔离主体、延迟背景信息 | 关键接触或双人表演不能被无意虚掉 |
| 深焦／深景深 | 同时观看多层行动 | 以构图和光线继续分主次，清楚不等于平板 |

黄金分割或螺旋可作为安排视线的辅助，不冒充比三分法更高级的必选构图。低角度、顶视属于角度，浅景深属于光学组织；可参与构图，但不把分类混成互斥列表。

画幅改变纵向／横向关系。9:16需要认真安排人物上下、门槛、手部与地理信息；横向双人关系可能需纵深、走位或适当拆镜。16:9、2.39:1也不能靠加黑边代替真实构图。字幕或界面安全区只在交付确实需要时预留。

## 焦距、机位与透视

先声明画幅基准，镜头建议再写单一焦距。广角／标准／长焦是相对概念；同一个50mm在不同画幅中的视角不同。

| 光学选择 | 可解决的问题 | 需要同时写清 |
|---|---|---|
| 较广视角、靠近主体 | 强化近远差、身体与空间、主观贴近 | 机位距离、边缘形变、人物脸部是否适合 |
| 中等视角 | 人物与环境平衡、自然关系观察 | 主体距离、画内信息与景深 |
| 较窄视角、远机位 | 隔离、观察、层叠背景或距离感 | 真实远机位、遮挡与行动范围；不把压缩全归因于焦距 |
| 微距／近摄 | 极小线索、材质、感官细节 | 实际尺度、接触与极浅景深的读图要求 |
| 变形宽银幕参考 | 横向空间、特定焦外和光学性格 | 画幅、挤压／还原及可见效果；不保证必有蓝色光斑 |

透视主要由摄影机位置决定。机位不动只换焦距，首先改变视角与取景；为了保持主体大小而移机时，近远关系才随位置改变。不要以“长焦压缩”掩盖缺失的机位描述。

T值表达透光，f值用于光圈几何；不用二者的相近写法编造精确景深。景深取决于画幅、焦距、光圈与对焦距离等；背景虚化还受主体—背景距离影响。T2不是所有情况下都极浅，T5.6也不保证全场清楚。

## 焦点是注意力的时间设计

- 固定焦点：指定人物近侧眼睛、接触点或关键物件；谁需要同时清楚。
- 跟焦：主体靠近／远离时如何维持目标，不把自动清晰当作已完成调度。
- 焦点转移：由什么触发、从谁／何物到谁／何物、持续大致多久、揭示后停在哪。先写真实的前后景关系。
- 主观失焦：触发、体验和恢复明确，不用失焦隐藏关键动作或模型错误。
- 两主体同时重要：调整站位、机位、光圈或拆镜；不以全程虚化另一角色代替关系设计。

## 运镜：动作定义与叙事用途

固定镜头同样是明确选择。支撑方式（手持、稳定器、轨道、摇臂）与运动轨迹是两个维度；“斯坦尼康”不等于具体路线，“电影感环绕”也没有完成设计。

| 类型 | 物理动作 | 可服务的叙事与端点 |
|---|---|---|
| 固定 | 相机位置与朝向基本不变 | 观察、等待、喜剧落点、让主体主动进入／离开 |
| 推进／拉远 Dolly in/out | 整机靠近／远离 | 注意力收束／信息展开；起止景别、距离与视差 |
| 横移 Truck | 整机左右移动 | 跟随、显露被挡信息、建立并列关系；遮挡变化 |
| 前后纵移 | 沿纵深行进，可配合主体 | 进入、离开、距离变化；主体大小如何变化 |
| 摇摄 Pan | 机位基本固定，朝向左右转 | 跟随视线、连接空间、延迟揭示；既可慢摇也可快摇 |
| 俯仰 Tilt | 机位基本固定，朝向上下转 | 从细节到体量、上下关系；不混同整体升降 |
| 整体升降 Pedestal | 整机垂直上升／下降 | 改变视高、显露空间；主体与地平线变化 |
| 摇臂／吊臂 Crane/Jib | 臂架带动空间位移，可成弧并配合旋转 | 视角接力、场面揭示；真实可行的三维路径 |
| 跟拍／前导 | 与主体移动保持某种相对关系 | 贴近体验、速度与路线；前后／侧面及相对距离 |
| 环绕 Arc/Orbit | 绕主体作弧线位移 | 关系变化、多方揭示或主观转折；角度、半径与轴线 |
| 光轴旋转 Roll | 绕镜头光轴旋转 | 失衡或形式变化；旋转起止和地平线状态 |
| 光学变焦 Zoom | 改焦距与视角，机位可不变 | 注意力或观察感；不同于移机的视差变化 |
| 移动变焦 Dolly zoom | 移机与反向变焦配合，主体大小近似保持 | 关键心理／空间失衡；背景变化与停点 |
| 甩镜 Whip pan | 快速摇摄形成运动模糊 | 突发注意、方向接力、暗切；接入镜方向和速度匹配 |
| 手持 | 人操作支撑形成有控制的微动，可同时位移 | 身体性、现场感；抖动幅度不能夺走动作可读性 |
| 稳定器移动 | 稳定支撑下执行路线 | 流动观察；起落稳定、转角及真实避障 |
| 穿越／掠过／俯冲 | 复合三维路线，不是单独设备名 | 空间揭示、速度与尺度变化；通道尺寸与落点 |

每次运动至少回答：**为何动；从哪到哪；朝向如何变；与主体关系；速度／加减速；焦点；最后给观众看什么。**

“跟随环绕”要写清环绕由哪侧到哪侧、主体是否继续走、相对距离和视线如何变化。“横移并摇摄”要说明位移与转向分别承担什么；不把摄影机、角色和背景都写成同方向滑动。

高速运动需要路径、幅度、加速、前后景视差和稳定落点。先有可辨的起始尺度，中途维持关键轮廓，最后留出读图时间；速度不等于持续抖动与不停切镜。

## 常见组合判断

先用机位和调度组织意义，再选设备词。近景反打不能无故改变角色站位；广角贴近不能同时要求毫无透视变化；快速穿越狭小空间不能忽略身体和道具的体积。

若一镜同时要求明显变焦、绕拍、升机、多人复杂交接与多次焦点转移，回到主行动线，保留有叙事作用的运动，必要时拆成有动机的连续镜头。不能因拆镜更方便而删掉剧情关键接触或改变事件结果。
