# 分镜到 H3 的装配约定

供所有导演制作线使用。导演在同一次任务中完成镜头设计并直接写成 H3；字段、标签、模式、上传编号、时间语法与默认批次以 [H3技能](../skills/h3-prompt-writing/SKILL.md)为准，不另建语法副本。

## 先设计，再直接写入正文

每镜先确定目的、时长、主体与空间起态、主要行动、摄影、必要光色、对白和声音、终态与下一镜的连接。内部检查完成后直接装配，不要求用户先批准一份中文构想再转换。用户已有确认的镜头继续沿用；触及故事或锁定项的变化先处理权限。

| 导演决定 | 模型正文应包含的内容 |
|---|---|
| 观看对象与关系 | 当前景别、机位、构图、视线和必要空间锚点 |
| 表演与动作 | 触发、可见回应、准备、接触、受力或所有权变化、结果 |
| 摄影与焦点 | 主体与摄影机分别的路径、速度、遮挡、关注对象和落点 |
| 光色与材质 | 本段有效视觉基准及在相应镜头发生的变化 |
| 原台词与声音 | 实际说话者、发声位置、原文、动作音时机与声画承接 |
| 连续性 | 相邻镜头与生成段的姿态、持物、动作相位、视线和声场状态 |

这些内容进入当前模式的时序主字段，而不是只留在块外说明。每段描述足以执行，不压成故事梗概；也不为凑字段重复人物小传、堆器材名或虚构精确参数。

## 有效设定与局部变化

设计时可按全片、场景、单镜组织共享设定。每个独立 H3 代码块展开该段实际生效的身份、空间、视觉、声音和起态，不依赖“同上”。单镜改变焦距、焦点、光色等后，在下一镜明确继续采用新值还是恢复原值。

同一物理空间保持真实光源与固定方位；画面左右会随机位变化。关键接触和两主体关系必须可读，不能用虚化、遮挡或过早切镜隐藏因果。

## 全片镜头与生成段

- 全片 SHOT 连续编号，表示实际连续画面；切镜另起镜头。核心关键帧、SHOT 与生成段不是一一对应。
- 按 H3 当前时长范围组织生成段，一个生成段可含多个镜头；同一长镜也可由连续生成段承接。生成段边界不自动增加电影切镜。
- 每段简明标注编号、时长、全片区间与覆盖的全片 SHOT；块内镜号和切点遵循 H3。局部修订、长镜跨段或参考复刻时补充必要映射，不能用全片或源片时间替代段内切点。
- 下一段从上一段终态继续，接续动作相位、道具归属、朝向、视线、速度与声音；交接不重演，道具不复原。不同生成任务的声音连续性不能仅凭提示词宣称已通过。
- 对白、反应、动作与转场留足理解时间。放不下时给出延长或拆段方案，不删原词、超速硬塞或悄悄新增事件。

## 一份可直接使用的交付

每段依次给出简明段信息与必要镜头映射、实际上传素材、一小段画面内容概述、一个完整可复制的 H3 代码块。概述只说明本段播放顺序、关键变化和终态，不再铺开另一份中文逐镜稿，也不提前写下段剧情。

素材清单、映射和人读说明在块外；模型需要的参考关系、机位动作和声画设计在块内。没有实际媒体就不创建其引用，分析过原视频不等于模型将收到它。

用户或调用方明确指定语言时将该约定传入 H3；否则遵循 H3 的默认语言规则。是否创建交接或保存 Markdown 遵循调用方工作流；本约定本身不新增落盘要求。

交付前检查原文覆盖、镜头目的、空间和动作连续、有效参数恢复、全片与分段时间以及真实素材映射。格式与文本检查不等于实际视频生成验证。
