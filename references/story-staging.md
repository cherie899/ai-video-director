# 叙事、表演与场面调度

## 从事件变成视听节拍

先确定场景开始与结束有什么变化：人物目标是否受阻，关系或权力如何移动，观众多知道了什么。把原文整理为有因果的节拍，每个节拍包含触发、行动、对方回应与结果；静止或沉默也可以是明确的拒绝、等待或信息延迟。

导演笔记允许解释已有情绪，拍摄正文则写可见可听的行为。“她意识到被骗”要落成原文支持的目光、动作中断、证据和反应；新增证据或改变人物所知须回到剧情权限。

| 当前戏剧问题 | 视听选择 | 执行时应明确 |
|---|---|---|
| 观众需要认清位置与目标 | 建立镜头或带行动的环境镜头 | 入口、目标、阻挡物、人物与出口关系 |
| 信息由角色发现 | 视线触发→对象→反应，或先反应后揭示 | 谁先知道，观众何时看清，揭示前不泄漏 |
| 观众比角色知道得多 | 先交代威胁，后观察角色靠近 | 威胁位置、距离、角色视野和持续时间 |
| 关系发生变化 | 双人构图、前后景距离、谁占据通道 | 接近／退让的行为原因，主导者如何影响另一人 |
| 一句台词改变局面 | 留在倾听者或延迟反打 | 触发词、可见反应、停顿何时结束 |
| 一个动作决定后果 | 看清准备、接触、结果 | 关键部位可辨，过程不能被装饰性切镜遮掉 |
| 情绪需要被体验 | 延长观察、减小运动、保留余波 | 角色正在等待什么，停留在哪个状态 |

## 镜头功能与覆盖

区分两组概念：

- **叙事核心镜头／辅助镜头**：描述对故事的作用。核心镜头可推动行动、揭示关系或提供不可替代的情绪体验；辅助镜头使动作更清楚、节奏更准确或转场更自然。二者都可使用任意景别。
- **Master shot／补充覆盖**：描述一场戏的覆盖组织。Master通常连续交代主要动作与人物空间；补充覆盖可以是中景、过肩、反打、反应或插入细节，不只特写。

建立镜头不一定放第一镜；先给局部再揭示空间可以成立，但要有意控制迷惑程度。主镜头不等于“全景”，辅助镜头不等于“空镜”。

每个候选镜头做删除试验：删除后是否损失行动因果、空间、关系、重要信息或一次情绪体验？辅助镜头再问：是否改善某个具体主行动的可读性、节拍或衔接？只重复已知信息的漂亮画面通常应合并或删去；有意重复用于积累、对照或等待时，写清其变化与目的。

## 视点与信息控制

| 视点组织 | 能带来的体验 | 避免的混淆 |
|---|---|---|
| 客观观察 | 让关系与行动自行显现 | 不把无依据全知信息放进角色视点 |
| 贴近某角色的限制视点 | 与其一起发现、误判、等待 | 镜头能见范围与角色已知信息一致 |
| 严格POV | 直接分享角色观看对象 | 机位眼高、朝向、距离和前后视线可对应 |
| 过肩／贴近反应 | 保留关系与对方存在 | 前景肩部真实归属，不凭空多出角色 |
| 主观感官 | 选择性声音、失焦、视野变化表达体验 | 用触发事件与恢复点交代，不靠滤镜含糊替代心理 |
| 全知／交叉观察 | 形成悬念、对照、并行动作 | 明确何时何地、是否同时，避免观众误读因果 |

镜头看向对象不自动等于角色POV。对焦转移也可能是导演引导，而非角色真的改变注意；根据叙事区分。

## 表演：行动目的先于情绪形容词

把“紧张地说”细化为角色试图怎样影响对方：试探、拖延、安抚、施压、掩饰、拒绝或争取。再选择少量能被看见的行为，不给每句台词同时塞入眼泪、颤抖、握拳、吞咽与急促呼吸。

倾听时也在行动。反打依据戏剧重心决定，不按说话人数机械轮转。关键回应可发生在对方话中、话后或沉默中，写明触发而非随机微表情。

复杂表演可按：**起态 → 触发 → 可见反应 → 行动选择 → 终态**。动作强弱、延迟和撤回有层次；同一句话的语气不掩盖其实际对象与目的。台词不为配合预想表情而自行改写。

动物或非人角色依据其身体结构和既定拟人程度设计。真实小猫用耳位、尾巴、身体重心、嗅闻和接近／退避表达，不默认拥有人的微笑、手掌、站立能力或表演习惯。用户明确的拟人设定优先。

## 空间先建立，关系再变化

导演工作笔记建立简短空间图：门窗、通道、障碍、楼梯、桌椅、重要物件与动机光源。空间东／西／南／北或A门／B窗是稳定位置；画面左／右由机位决定，两者不能互相代替。

给主要角色记录起点、朝向、距离、视线对象与所持道具。调度用前进、退让、绕行、坐下、挡门、让出通道、占据前景等动作表达关系；每次移动要有剧情或行为依据。人物不能为了对称构图突然换边。

| 调度策略 | 可解决的问题 | 镜头内需要交代 |
|---|---|---|
| 同框对峙 | 两人关系与权力平衡 | 间距、身体朝向、谁先打破静止 |
| 前后景分层 | 分离注意、隐瞒、压迫或等待 | 各层发生什么，焦点先后及遮挡 |
| 接近／后退 | 试探、信任、拒绝、压力 | 谁驱动变化，对方如何回应 |
| 通道与门槛 | 准入、阻挡、离开与犹豫 | 门开合方向、谁控制出口、最终位置 |
| 绕物体／借遮挡 | 关系改变、躲避或信息隐藏 | 遮挡物实体、出现消失的时点 |
| 群体分区 | 群像内部关系与主次 | 主行动、次反应、谁是当前注意中心 |

多人场面一次保持一个清楚的注意中心；其他动作作为背景层次，不让所有角色同步转头、伸手或说话。先确定是否需要同框关系，再决定是否拆近景。

## 轴线、视线与连续性

双人连线、人物行进路线或角色与目标之间都可能形成主要轴线。常规连续性镜头尽量保持同侧，以维持屏幕方向和对看关系。越轴不是禁令，但要有可见过轴运动、中性正面机位、重新建立空间或明确的叙事动机。

- **视线**：人物看谁、目标高低和左右须可接。A向画右看B，B的反打应能回应；儿童、猫、坐姿者和站姿者眼高不同。
- **动作方向**：追逐先交代路线、目标、障碍与出口。动作进入下一镜继续向目标推进；方向反转须看到转弯、改变机位或重新建立。
- **角度与景别差异**：相近机位同景别直接切换可能跳切。约30度是常见检查起点，也可用明显景别、动作或构图变化解决；有意跳切另论。
- **动接动**：切在动作中，但下一镜承接相同动作阶段，不把举手重演一次；省略中间过程时明确是时间压缩。
- **静接静**：匹配姿态、持物、视线及情绪状态，停顿有目的，不让表情突然复位。
- **服化与环境**：衣物、伤痕、湿度、门开度、杯中液位、餐食余量和光源方向在相同时间连续。

对抓握、交接、开门、上下楼、坐下等动作逐项核对：**准备 → 接触 → 受力／所有权变化 → 完成**。说清哪只手／爪、持物点、支撑面及释放时机；关键状态变化留在可见区域，不用离屏跳变掩盖逻辑。

## 节拍到镜头的常见组织

以下是候选组织方式，不是每场照抄的景别公式：

| 情节 | 可选组织 | 选择依据 |
|---|---|---|
| 进入陌生空间 | 环境／行动全景→目标→人物反应；也可从局部逐渐揭示 | 观众需要先认清什么，何时提供整体 |
| 对话试探 | 双人关系→有变化一方→倾听者→关系重组 | 留在谁身上更能看到台词后果 |
| 发现线索 | 视线／动作触发→细节→反应→补空间 | 线索应清楚到什么程度，是否延迟揭示 |
| 做出决定 | 持续观察→关键反应→落实行动的细节 | 决定不是只有表情，行动如何证明 |
| 探索悬疑 | 区域与路线→异常→角色反应→下一步行动 | 探索范围、危险可知程度、主客观视点 |
| 动作攻防 | 空间关系→准备→接触／闪避→结果→重新定位 | 动作方向、距离、重量和危险可读 |
| 追逐逃离 | 路线→跟随速度→障碍与代价→距离变化→脱险结果 | 空间地理与速度同时成立 |
| 离场收束 | 行动结果→反应／余波→环境落点 | 情绪需要靠近、停留还是逐渐远离 |

不要用“快切”替代动作设计，也不要用“长镜头”替代镜内变化。长度服务于信息、表演和体验；关键动作至少有机会被观众读懂。

## AI拍摄分镜的执行清晰度

身份、场景和道具基准进入有效统一设定；每镜描写当前状态，而非把整个人物小传反复复制。连续场景以状态接续，不能每镜都从站定、抬头、开始走重新来过。

一镜可以有多个连续节拍，但要有一个可读的主行动线。摄影机与主体可同时运动，分别写轨迹、相对距离、遮挡和落点；复杂度来自戏剧需要，不来自同时堆动作。

关键长镜头先设计完整调度与焦点路线；需要降低执行复杂度时给保留信息与情绪的替代切法，标出代价。仅改变机位或覆盖属于导演选择；改动结果、台词或锁定项须交用户决定。

以上约束改善文本可执行性，不保证任何特定模型会稳定生成；真正成片仍需另行验证。
