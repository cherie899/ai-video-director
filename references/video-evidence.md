# 视频拉片的证据与记录

仅在实际视频分析或复刻任务中读取。复刻等级、确认点与交付文件由调用方工作流决定；本文件只规定观察依据与逐镜记录。

## 可验证的声画范围

使用当前环境可用的视频访问、播放、媒体探测、连续帧检查与音频工具，记录实际素材、时长、画幅、帧率或时间戳依据、音轨情况、检查方法与覆盖区间。

先完整观看声画，或检查覆盖全片的连续帧序列与音轨，再复核切点、运动起落、关键接触和转场两端。稀疏抽帧、封面、缩略图和字幕不能独立证明完整镜头边界、运镜与声音。

| 访问条件 | 可交付的事实边界 |
|---|---|
| 只有静帧 | 构图、光色与可见状态；运动、切点和声音未验证 |
| 只有片段 | 仅分析已检查区间，列缺口，不编造剩余镜头 |
| 音轨存在但未听取 | 明确未听取，不写“无对白”或“无配乐” |
| 媒体信息确认无音轨 | 原片记无音轨，新片声音建议另列 |
| 缺可靠时间戳 | 保留可确认镜序，时间记估计或待测，不伪造帧级精度 |

## 镜头边界与时间

真实剪切或转场构成源镜边界；同镜摇摄、变焦、移焦、主体移动和镜内遮挡不自动另算镜头。连续声轨不能证明无切镜，隐藏剪辑证据不足时标疑似并说明依据。

源镜从 R001 连续编号，覆盖已检查的全部时间结构，片头、黑场、定格和片尾均按实际计入。可变帧率依据时间戳，不用帧号除标称帧率制造精度；估计切点注明约数、误差或依据，叠化记录重叠区间。

## 逐镜记录

每镜记录：源镜号、起止与时长可信度、可见行动和信息、景别机位构图焦点、主体与摄影机运动、空间、光色美术、对白与其他声音证据、切点转场及叙事作用。长记录可按同一镜号拆成视觉和声音两表，不强求超宽表格。

明确区分观察事实、导演推断和新片复刻建议。主体变大可能来自推进、变焦或主体靠近；结合视差、遮挡、透视和背景比例判断。无依据时不声称精确设备、焦距、光圈或已证实的传播效果。

## 从证据到复刻

分别说明保留的镜头机制和用户批准的变化。原剧本的剧情依据与参考片的摄影依据分开，不让参考视频默默替换故事。

换成动物或其他主体时，检查尺度、肢体、接触和行为条件；涉及锁定项则提出最小适配方案。源镜时间、新片时间、全片 SHOT 和生成段映射分别记录；一条长镜因生成上限分段，不伪造新增源片切点。

对白听不清则标未知，不发明原台词。原片没有音乐与用户要求新片配乐可同时成立，新增声音注明为设计建议。实际使用的媒体标签与模式由 H3 技能按真实上传用途处理。

分析完整只代表已观察范围内有证据；未来生成片的身份、动作、口型、声音与剪辑仍需实片验证。
