# H3 提示词

可独立调用，也可承接导演已确认的设计。只装配提示词，不新增剧情、制作图片或调用视频生成；缺少决定性信息时集中询问，不启动完整导演流程。

## 语言与格式

正文默认中文，用户或调用方明确指定其他语言时采用指定语言。原对白、歌词、画内文字及其标点保持原样；字段名、标签、切点语法和固定关系枚举不翻译。参考中的英文案例只演示结构，不规定输出语言、题材或风格。

先确定实际输入模式，再按下表定位章节；可先查看标题索引，不默认全文读取。已读且仍有效的规范直接复用，变化或缺失时只补读当前所需章节。案例仅在需要核对格式时读取。

| 实际输入用途 | 模式与读取范围 |
|---|---|
| 无媒体，仅文字 | T2VA：[基础指南](references/base-en.txt) §2.2三个字段及§4通用声画规则；跳过图片对齐和案例 |
| 仅用图片锁定实际首帧、首尾帧或尾帧 | I2VA / FL2VA / L2VA：基础指南§2、§3对应模式及§4；跳过其他模式和案例 |
| 仅图片全能参考，包括身份、空间、动作、分镜或段内具体帧锚点 | Ref2VA：[全能参考指南](references/ref-en.txt) §1、§2.1–2.2、§3、§4.1、§5.2–5.3及基础指南§4；有对白时加读§5.4 |
| 同时使用多类参考，或视频/音频参与参考、编辑、延续 | 在图片参考路径上，仅补读实际需要的§2.3–2.5、§4.2、§5.4与§6 |

先区分素材提供的属性与必须对齐的具体画面。仅首尾帧槽位时采用对应基础模式。首尾帧同时搭配其他图片、视频或音频参考时，按实际平台输入能力选择全能参考并写明帧对齐关系。输入能力不支持该组合时说明缺口，请用户取舍必要约束。

全能参考中，指定某张图作为实际首帧、尾帧或段内具体帧，采用 `keyframe completion`，即使尚未给秒数也按具体帧锚点处理。仅参考身份、空间或分镜设计时采用 `reference generation`。其余任务类型按素材实际用途组合。

## 素材与上传编号

1. 实际查看素材，先解析用户原始编号与文件的对应关系。导演调用时仅选当前段所需的最新已确认版本。有图片参考时，按[参考图分工](../../references/image-standards.md#参考图分工)标明每张图的用途，并把模型需要的参考限制写入正文。
2. 用户指定的上传位置及首尾帧槽位优先。其余按任务重要性排序，同等重要时保留原顺序；产品主导项目可将产品优先。
3. 对选用图片连续重新编号。基础模式的首尾帧槽位按基础指南固定，不能为重要性排序而交换，也不暗示可额外上传参考图。
4. 代码块外逐行列出「图片序号 / `<Picture N>` — 实际文件名或链接 — 用途」，提示按此顺序上传。无文件名时用可辨认的视觉描述及原上传位置，不编造文件名；排除项另列原因。无图片时省略图片清单，实际使用的视频或音频同样列明文件与标签。
5. `<Picture N>` 是上传素材图片的编号标识，与清单中的实际文件名一一对应。正文引用图片时使用本段重排后的编号。Subject 表示从素材中复用的内容，Picture、Subject、Video、Audio 各自独立编号。

## 段落装配

- 每段独立写全身份、声线、空间、起始状态和镜头路线；重设素材标签，按实际首次发声顺序分配半角括号格式的 `(S1)`、`(S2)` 等编号，不依赖上一段的“同上”。
- 对白逐字写进 `<d>`，按实际发声语言加标签；动作和语气位于标签外。跨切镜对白按基础指南配对 `<scenetrans>`，不以截断标签掩盖漏词。
- `[Shot 1]` 不加切点；后续使用 `[Shot N] At MM:SS.mmm,`，段内切点严格递增且小于总时长。时长、切点和镜内节点使用0.5秒整数倍。
- 按本地指南的4–15秒单段范围组织，可依用户明确提供的平台规格更新，不将其声称为联网核验的最新限制。对白与行动放不下时，提出保留原词的自然拆段；已确认路线的实质变化先确认。
- 环境和物理声音归入 `overall_soundscape`；用户、原文及已确认设计均未要求配乐时，`non_diegetic_music: N/A`。无配乐不等于静音。

## 交付

每段依次给出段落编号与时长、实际上传素材及标签、一个包含完整字段和正文的 `text` 代码块。导演调用时，在代码块前加一小段画面概述。跨段长镜或复刻任务补充必要的全片镜号与段内镜号映射。文件路径、上传操作及人读说明放在块外，模型需要的参考关系写入正文，每段可独立复制。

默认聊天交付，每批最多3段，等待确认后继续。只有用户或调用方明确要求时才保存文件。由导演调用时沿用当前阶段、素材版本和确认结果，不重跑导演设计。

交付前核对模式、字段、上传映射、参考标签、原文覆盖、说话者、切点与时间预算；格式通过不等于实际视频及声画接缝已经验证。
